# 🌱 Sistema Automático de Detecção de Umidade de uma Planta


## 📖 Sobre o Projeto
Este projeto consiste na criação de um sistema de monitoramento de umidade do solo utilizando Arduino, sensor de umidade e LEDs indicadores.

O sensor de umidade verifica a quantidade de água presente na terra, identificando se o solo está seco, com umidade adequada ou muito úmido.

Os LEDs indicam as condições do solo: o LED vermelho sinaliza que a terra está muito seca, o LED amarelo indica um nível intermediário de umidade e o LED verde representa que a terra está com umidade adequada para a planta.

O projeto foi desenvolvido e simulado utilizando o Tinkercad.
