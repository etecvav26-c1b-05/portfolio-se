🏠 Telhado Automático

📖 Sobre o Projeto

Este projeto consiste na criação de um sistema de telhado automático utilizando Arduino, LDR, sensor de temperatura TMP36 e servo motor.

O LDR controla a abertura de acordo com a luminosidade, enquanto o sensor TMP36 verifica a temperatura. O servo motor utiliza 0º para o telhado fechado e 90º para o telhado aberto.

LEDs verde e vermelho indicam, respectivamente, quando o telhado está aberto ou fechado. O projeto foi desenvolvido e simulado utilizando o Tinkercad.
